# Share TF2 assets across Derived Maps

> Amended by ADR 0006: shared assets are the prop models and skies built maps share on the asset host, not a Shared Asset Pack.

Published and Ad-hoc Derived Maps reference one versioned Shared Asset Pack for reusable TF2 materials, prop models, and skyboxes while retaining BSP-embedded custom assets per Map Build. This trades standalone map packages for substantially smaller Derived Maps and one consistent high-quality Conversion Profile without duplicating common content in every map.
